# Design-Psychology Master — 認知心理學與頂級視覺雙軌心智模型

> **核心哲學**：拒絕純粹裝飾性 AI 廢稿（AI Slop）與死氣沉沉的工程師資料庫視圖。本 Skill 賦予 Agent 跨領域的「認知與視覺雙軌心智模型」，在「吸引專注（視覺張力）」與「維護專注（避免認知過載）」之間取得極致平衡，並賦予使用者充分的掌控感（User Agency & Autonomy）以激發深層學習心流。

---

## 1. 核心四大模組架構

### 模組一：心理學與行為科學引擎 (The Psychology Engine)
1. **格式塔心理學 (Gestalt Principles)**：
   - **接近性 (Proximity)**：邏輯相關的元件距離更近；段落與其專屬註解相距不超過 8-12px。
   - **相似性 (Similarity)**：相同功能層級採用一致的幾何形態（如所有主動測驗皆為圓角矩形，所有導讀標籤皆為微型膠囊）。
   - **連續性 (Continuity)**：以細微引導線、階梯式節點（Roadmap Tree）引導學生的閱讀與探索動線。
   - **封閉性 (Closure)**：運用柔和的卡片背景或微陰影邊框界定資訊邊界，但不濫用生硬的粗黑外框。
2. **認知負荷理論 (Cognitive Load Theory - Sweller)**：
   - **內在負荷 (Intrinsic Load)**：尊重學術知識本身的複雜度，不做廉價的過度簡化。
   - **外在負荷 (Extraneous Load - 嚴格消除)**：消除無意義的裝飾性動態、跳動秒數計時器、以及不必要的視覺邊框與噪點。
   - **增長負荷 (Germane Load - 積極促進)**：提供心智圖、資訊圖表與雙重編碼架構，引導大腦將工作記憶轉化為基模（Schema）。
3. **唐納·諾曼的情感化設計 (Emotional Design by Don Norman)**：
   - **本能層 (Visceral)**：第一眼的美學直覺——溫潤紙張色調、典雅無襯線/襯線字體、微溫呼吸感、抗疲勞配色。
   - **行為層 (Behavioral)**：極致易用性——0.75s 緩動滑塊反饋、明確的點擊熱區、無延遲即時跳轉。
   - **反思層 (Reflective)**：學習掌控感與成就感——清晰的自律歷程記錄、自主定制面板、無焦慮的自信心。
4. **行為改變與自我決定論 (Fogg B=MAP & Self-Determination Theory)**：
   - **自主感 (Autonomy)**：允許使用者完全自訂面板、佈局、配色與功能排列，不強迫單一視角。
   - **勝任感 (Competence)**：即時反饋、鷹架過渡（Scaffolding），讓每次測驗與研讀都看見具體成長。
   - **動機與觸發 (Motivation & Trigger)**：在聽完導讀的「峰值時刻」及時觸發「5分鐘主動提取測驗」。

### 模組二：專業設計與美學執行引擎 (The Professional Design Engine)
1. **視覺階層與版面配置 (Visual Hierarchy & Layout)**：
   - 採用 **8pt 網格系統** (`8px`, `16px`, `24px`, `32px`, `48px`)，維護嚴格的幾何節奏。
   - 留白（Whitespace）作為第一等設計元素，絕不因空間有剩而填滿次要內容。
   - **F-shape 與 Z-shape 閱讀動線**：重要導航與標籤置於視覺啟動點，閱讀正文保持 65-75 字元最佳行寬（Optimal Measure）。
2. **色彩心理學與 60-30-10 法則**：
   - **60% 基底色 (Dominant Background)**：低彩度柔和茶白、冷灰礦底或夜森沉香色（提供心理安全感）。
   - **30% 結構色 (Structural Cards & Text)**：純白天鵝絨卡片或暗調懸浮面板，墨黑或柔白字體。
   - **10% 強調色 (Accent & Anchors)**：鼠尾草綠、板岩青翠、暖赤陶色（僅用於關鍵按鈕與進度標記）。
   - 嚴格遵循 **WCAG AA/AAA 規範**，文字對比度最低 4.5:1，重要標題達 7:1。
3. **字體與文字編排 (Typography & Micro-Typography)**：
   - 標題行高 `1.2-1.3`，正文行高 `1.7-1.85`，段間距大於行距。
   - 數字採用等寬字體（`tabular-nums`），避免數據變動造成介面抖動。
   - 禁止生硬的中英文混排空隙突兀，採用純文字膠囊，減少無意義 Emoji 與圖標雜訊。

### 模組三：動態分級與記憶鷹架 (Visual Tiering & Memory Scaffolding)
1. **動態與靜態的黃金分級 (Visual Tiering)**：
   - **靜態基底 (70-80%)**：穩定的網格、靜止的容器、柔和的閱讀畫布，維護學生的心流不被打斷。
   - **動態引導 (20-30%)**：
     - 動態僅用於「引導視線」或「標記當前焦點」（如音訊導讀時律動聲波、首頁載入時的 0.8s 階梯舒展）。
     - **非永久性原則**：一旦步驟結束，動態立即停止化為靜態結構，絕不在學生精讀時產生無休止的視覺震盪。
2. **記憶輔助與雙重編碼 (Dual-Coding Theory by Paivio)**：
   - **空間隱喻 (Spatial Metaphors)**：左因右果、上層下級、相鄰同類。利用空間維度強化記憶提取。
   - **視覺錨點 (Visual Anchoring)**：將抽像文字轉化為向量心智圖、數據矩陣與資訊圖表。
   - **語意化色彩 (Semantic Coloring)**：同一學科模組始終維持統一色彩代碼。
   - **視覺停頓與呼吸節律 (Consolidation Whitespace)**：密集段落後必留充足空白，給予大腦短期記憶向長期記憶固化的生理時間。

---

### 模組四：雙向防錯與審查迴圈 (Critique & Red-Teaming Loop)
每次產出或重構 UI 介面，必須經過雙重角色自動檢核：
- **視覺設計師視角 (The Designer Critique)**：
  - [ ] 視覺焦點是否單一且明確？
  - [ ] 是否存在任何不對稱的 margin / padding 破綻？
  - [ ] 是否滿足 8pt 網格與 60-30-10 配色比例？
  - [ ] 圓角、陰影與字體層級是否一致？
- **認知心理學家視角 (The Psychologist Critique)**：
  - [ ] 是否存在誘導焦慮的倒數或威脅性警報？
  - [ ] 同一畫面上的視覺焦點是否超過 3 個（7±2 短期記憶瓶頸）？
  - [ ] 動態元素是否干擾閱讀工作記憶？
  - [ ] 是否賦予使用者充分的掌控感與自訂權限（User Agency）？

## 2. 執行指令與自動審查腳本

執行設計心理學自動化檢核：

```bash
python3 .agents/skills/design-psychology-master/scripts/design_audit.py
```

或傳入特定 HTML/CSS 檔案進行靜態分析：

```bash
python3 .agents/skills/design-psychology-master/scripts/design_audit.py path/to/file.html
```

## 3. 在 Agent 開發流程中的觸發時機

當使用者提出以下需求時，主動激活本 Skill：
- 「設計/重構學習平台、課程頁面或知識管理系統」
- 「界面太死氣沉沉，或太花俏干擾使用者」
- 「排版不協調、缺乏高級感或學生容易感到疲倦」
- 「希望兼具動態儀式感與深層專注力」
- 「希望使用者擁有自訂與排列組合的掌控感」
