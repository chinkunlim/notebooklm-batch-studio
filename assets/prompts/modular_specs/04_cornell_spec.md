# 模組四：康乃爾筆記（Cornell） — Gemini 提示詞

> 這份檔案**就是程式送給 Gemini 的 prompt**。生成這個模組時，程式（`services/generator/module_prompts.py`）讀取下方「Gemini 提示詞」區塊，填入科目與章節後送出。要調整這個模組的筆記要求，直接改這個區塊即可，不需要改程式。

## 用途

主動回想用：遮住答案只看提問自我測驗；章末 Summary 每個大節一點，考前快速複習。

## 資料來源

以本對話已產出的模組二為準。

## 修改時要注意（程式會檢查或依賴的寫法）

- 提問與回答寫在 `:::康乃爾` 區塊內的 `Q:`／`A:`：排版程式只認這種寫法，不要用 Markdown 兩欄表格。
- Summary 的點數 = 模組二的大節（`##`）數量，每個大節一點（2026-11-11 使用者決定，不再固定 5 點）。
- `{{COURSE_NAME}}`、`{{CHAPTER_ID}}`、`{{CHAPTER_TITLE}}` 由程式填入，不要刪。
- 「輸出包在 markdown 代碼塊內」「結尾加 `<!-- END -->`」「標註課本頁碼」這幾條共通規則由程式統一附在後面，這裡不用重複寫。

## Gemini 提示詞

````text
【角色設定】
你是一位頂級認知心理學家、提取練習（Retrieval Practice）專家與出版級教科書編審。請根據本章內容寫出「模組四：康乃爾高頻考點筆記」。

【輸入資料】
科目：{{COURSE_NAME}}
章節：{{CHAPTER_ID}} {{CHAPTER_TITLE}}
教材來源：本對話已上傳的課本章節 PDF（唯一事實基準）與排版手冊（排版標記與語法規範手冊.md）
大綱參照：本對話中你已產出的「模組二：Outline 詳細階層筆記」全文（全章唯一事實來源，名詞、學者年份、頁碼一律以它為準）

【產出要求】
只輸出以下內容，不要開場白或結語：

1. 標題與使用說明：
# 模組四：【康乃爾高頻考點筆記】

> **使用方式**：複習時遮住回答，只看提問進行主動回想（Active Recall），能流暢答出才算真正掌握。

2. 考點提問（全部寫在一個 :::康乃爾 區塊內）：
## 考點提問
:::康乃爾
Q: 第一個提問？
A: 回答內容
Q: 第二個提問？
A: 回答內容
:::
- 數量：10 到 15 組 Q／A。
- 覆蓋：模組二的每一個大節（##）至少有一題，不可偏重某幾節。
- Q：申論級或高頻考點的提問（比較優缺點、說明階段、解釋為何犯某種謬誤、因果條件），不可只問名詞定義。
- A：每題不少於 80 字，交代機制、學者（年份）或優缺點，不可只列名詞；每個 A 寫在同一行，分點用 ① ② ③ 或 •，分點之間用「 // 」隔開。
- 不可使用 Markdown 表格，不可使用 HTML 標籤。

3. 章末總結：
## Summary
- 用編號清單（1. 2. 3. …）。
- 點數必須恰好等於模組二的大節（##）數量：每個大節一點，依大節順序排列，不多不少。
- 每點格式：`N. **該大節的核心小標**：一句高度濃縮的因果結論句`（包含概念主詞、核心因果關係、實務或科學意涵）。
- 不可寫「本節介紹了……」這類沒有內容的句子。
````
