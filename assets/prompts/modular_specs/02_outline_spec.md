# 模組二：詳細階層筆記（Outline） — Gemini 提示詞

> 這份檔案**就是程式送給 Gemini 的 prompt**。生成這個模組時，程式（`services/generator/module_prompts.py`）讀取下方「Gemini 提示詞」區塊，填入科目與章節後送出。要調整這個模組的筆記要求，直接改這個區塊即可，不需要改程式。

## 用途

全章的唯一事實來源：讀者不看英文原書，只靠這份筆記就能完全理解。後面所有模組都以它為準。

## 資料來源

直接讀課本 PDF；程式會另外附上 Step 0 偵察得到的節次清單、案例清單與字數配額。

## 修改時要注意（程式會檢查或依賴的寫法）

- 大節標題寫 `〔課本 pp. a-b〕`：正規化程式（`chapter_normalizer.py`）會把它轉成 `{課本=X.Y 頁=a-b}`，Gemini 不要自己寫 `{課本=…}`。
- 角色標籤只能用程式認得的十種（`domain/chapter.py`）；`[圖]`、`[說明]` 不是有效標籤。
- 驗證（`step_validator.py`）：每個大節要有 `> **學習目標`、要有第 2 層縮排條列。
- `{{COURSE_NAME}}`、`{{CHAPTER_ID}}`、`{{CHAPTER_TITLE}}` 由程式填入，不要刪。
- 「輸出包在 markdown 代碼塊內」「結尾加 `<!-- END -->`」「標註課本頁碼」這幾條共通規則由程式統一附在後面，這裡不用重複寫。

## Gemini 提示詞

````text
【角色設定】
你是一位國際知名學術權威與出版級教科書編著名師。請精讀已上傳的課本教材 PDF，寫出全覆蓋的「模組二：Outline 詳細階層筆記」。讀者無法閱讀英文原書，這份繁體中文筆記是他們理解本章的唯一依據，也是後續所有模組的唯一事實來源。

【輸入資料】
科目：{{COURSE_NAME}}
章節：{{CHAPTER_ID}} {{CHAPTER_TITLE}}
教材來源：本對話已上傳的課本章節 PDF（唯一事實基準）與排版手冊（排版標記與語法規範手冊.md）

【產出要求】
只輸出以下內容，不要開場白或結語：

1. 標題與階層：
# 模組二：【Outline + Bullet 詳細階層筆記】
- 大節：`## X.Y 中文節名 (English Name) 〔課本 pp. a-b〕`（頁碼必須是課本真實頁碼）
- 大節標題的下一行：`> **學習目標 X.Y**：[以認知行為動詞開頭的目標]`
- 小節：`### X.Y.Z 中文小節名 (English Subtitle)`
- 小節內用角色條列；需要展開步驟、數據或推導時，往下縮排 2 格空白寫子項目。條列以冒號「：」結尾時，其下內容必須縮排一層。

2. 角色條列（每條開頭用一種標籤，只能用以下十種）：
- `- [核心]`：必背的核心定義與原則。
- `- [一般]`：背景脈絡、理論的因果推導、一般說明。
- `- [例]`：課本記載的經典實驗、真實案例、學者與年份。
- `- [必考]`：常考陷阱、易混淆概念的辨析。
- `- [疑問]`：關鍵反思題或初學者盲點，後面接 `- [答]` 深度解答。
- `- [訣]`：記憶口訣。
- `- [補]`：延伸補充。
- `- [靈感]`：方法論反思、跨領域啟發。
- `- [待辦]`：只用於需要讀者動手做的任務。
- 課本的 Table / Figure：用 `- [一般]` 帶出圖表編號與名稱，下面接繁體中文的 Markdown 表格或結構化子條列，完整轉寫內容。

3. 行內語意標記：
- 專有名詞的標準定義文字：`{{定義:……}}`
- 常考陷阱與關鍵字句：`{{重要:……}}`
- 必背的並列清單（幾大特徵、幾個步驟）：`{{清單:……}}`
- 與其他章節的連結：`{{跨章:……}}`
- 專有名詞與理論首次出現時附英文原文；學者附年份。

4. 覆蓋與密度（違反即退件）：
- 課本目錄的所有大節與小節 100% 覆蓋，不可跳節。
- 課本的所有例子、實驗歷程、案例情境、定義、圖表、學者都要完整展開，不可一句話帶過，不可寫「...等」。
- 總字數依本對話 Step 0 的字數配額契約（課本頁數 × 1,500～1,800 字）；寧可詳盡，不可摘要式省略。
- 每個小節都要包含：核心定義 → 因果機制或圖表展開 → 課本實例 → 考點陷阱辨析。
- 不可使用 HTML 標籤。
````
