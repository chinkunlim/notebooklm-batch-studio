# 模組六：費曼白話教練（Feynman） — Gemini 提示詞

> 這份檔案**就是程式送給 Gemini 的 prompt**。生成這個模組時，程式（`services/generator/module_prompts.py`）讀取下方「Gemini 提示詞」區塊，填入科目與章節後送出。要調整這個模組的筆記要求，直接改這個區塊即可，不需要改程式。

## 用途

把本章最抽象的三個課題用日常生活講到小學生也懂，再對回課本，最後點出考場陷阱。

## 資料來源

以本對話已產出的模組二為準。

## 修改時要注意（程式會檢查或依賴的寫法）

- 課題標題用 `## 費曼課題：…`：驗證（`step_validator.py`）找不到 3 個這種標題會判失敗。
- 每題三段（比喻 → 對回課本 → 誤解），與心研法成品多數章節的做法一致。
- `{{COURSE_NAME}}`、`{{CHAPTER_ID}}`、`{{CHAPTER_TITLE}}` 由程式填入，不要刪。
- 「輸出包在 markdown 代碼塊內」「結尾加 `<!-- END -->`」「標註課本頁碼」這幾條共通規則由程式統一附在後面，這裡不用重複寫。

## Gemini 提示詞

````text
【角色設定】
你是一位精通費曼學習法（Feynman Technique）的頂級科普大師與學習教練。請找出本章最抽象、最艱澀、最容易讓初學者卡關的 3 個課題，寫成「模組六：費曼白話教練」。

【輸入資料】
科目：{{COURSE_NAME}}
章節：{{CHAPTER_ID}} {{CHAPTER_TITLE}}
教材來源：本對話已上傳的課本章節 PDF（唯一事實基準）與排版手冊（排版標記與語法規範手冊.md）
大綱參照：本對話中你已產出的「模組二：Outline 詳細階層筆記」全文（全章唯一事實來源，名詞、學者年份、頁碼一律以它為準）

【產出要求】
只輸出以下內容，不要開場白或結語：

1. 標題：
# 模組六：【費曼白話教練】

2. 課題：恰好 3 個，每個課題的標題格式：
## 費曼課題：[具體生動的疑問句？]

3. 每個課題固定三個小節，順序不可調換、不可合併、不可省略；前兩個小節的標題要在冒號後寫出主題：
### 白話生活比喻：[這個比喻的主題，例如「地板濕了，代表一定剛下過雨嗎？」]
- 用完全沒有學術術語的日常情境（廚房、交通、購物、戀愛、遊戲、校園生活等），講到「老奶奶或小學生也能秒懂」。
- 要有情節與角色互動，把抽象機制與因果鏈講成直覺常識；不可一句話帶過。

### 對應課本概念：[對應的課本概念名稱 (English Name)]
- 把比喻中的每個元素一一對回課本的專有名詞（附英文原文與課本頁碼）。
- 涉及推導或因果關係時，列出清楚的邏輯式或步驟（例如 $P \rightarrow Q$），並說明課本為何要這樣嚴謹定義。

### 常見誤解與考場防呆
- 用以下兩種條列呈現對比：
- [疑問] **學生常見盲點**：初學者最容易犯的直覺錯誤或迷思。
- [核心] **一秒破題判別法**：一針見血指出盲點關鍵，給出考場上可以立刻使用的判別方法。

4. 字數：
- 每個課題不少於 1,000 字（白話生活比喻約佔一半）。
````
