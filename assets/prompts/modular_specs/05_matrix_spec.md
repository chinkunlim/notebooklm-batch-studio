# 模組五：比較矩陣（Matrix） — Gemini 提示詞

> 這份檔案**就是程式送給 Gemini 的 prompt**。生成這個模組時，程式（`services/generator/module_prompts.py`）讀取下方「Gemini 提示詞」區塊，填入科目與章節後送出。要調整這個模組的筆記要求，直接改這個區塊即可，不需要改程式。

## 用途

把容易混淆的概念放在同一張表裡逐項對照，一眼看出差異。

## 資料來源

以本對話已產出的模組二為準。

## 修改時要注意（程式會檢查或依賴的寫法）

- 每個主題用 `## 主題名稱` 加 `{表 名稱=主題名稱}`，主題之間用 `---` 隔開：排版與稽核程式依這些標記辨識表格。
- 驗證（`step_validator.py`）：表格少於 2 張會判失敗。
- `{{COURSE_NAME}}`、`{{CHAPTER_ID}}`、`{{CHAPTER_TITLE}}` 由程式填入，不要刪。
- 「輸出包在 markdown 代碼塊內」「結尾加 `<!-- END -->`」「標註課本頁碼」這幾條共通規則由程式統一附在後面，這裡不用重複寫。

## Gemini 提示詞

````text
【角色設定】
你是一位精通概念辨析與多維比較的頂級學術名師與出版級教材主編。請根據本章內容寫出「模組五：多維主題對抗比較矩陣」。

【輸入資料】
科目：{{COURSE_NAME}}
章節：{{CHAPTER_ID}} {{CHAPTER_TITLE}}
教材來源：本對話已上傳的課本章節 PDF（唯一事實基準）與排版手冊（排版標記與語法規範手冊.md）
大綱參照：本對話中你已產出的「模組二：Outline 詳細階層筆記」全文（全章唯一事實來源，名詞、學者年份、頁碼一律以它為準）

【產出要求】
只輸出以下內容，不要開場白或結語：

1. 標題：
# 模組五：【多維主題對抗比較矩陣】

2. 依主題拆成多張表，不可把整章塞進一張大表：
- 全章挑 4 個最核心、最容易混淆的比較主題（成對對立的概念、多階段的演進、同類不同方法的比較等）。
- 每個主題的寫法：
## 主題名稱
{表 名稱=主題名稱}
| 比較維度 | 對象 A 中文名 (English) | 對象 B 中文名 (English) |
| :--- | :--- | :--- |
| … | … | … |
- 一個主題內容太多時可以拆成 2 張表，每張表上方各有自己的 `{表 名稱=…}`。
- 主題與主題之間用單獨一行 `---` 隔開。

3. 比較維度要因題制宜：
- 每張表至少 5 列比較維度。
- 維度必須依該主題量身設計、具鑑別力（例如：代表學者與年份、核心定義、運作機制、研究者是否主動操弄、能否推論因果、優點與貢獻、限制與典型陷阱、課本經典案例或話術實例），不可每張表都用同一組維度。

4. 密度與格式：
- 每個儲存格 30 到 80 字，寫出實質內容；不可出現「無」「同左」「略」「參見前文」。
- 儲存格內需要分點時用「 // 」隔開，不可使用 HTML 標籤，不可破壞表格語法。
````
