2.1　去極化

神經元在休息時並不是「沒有電」。細胞膜內外維持約 −70 mV 的靜止膜電位，靠的是鈉鉀幫浦持續消耗 ATP，把三個鈉離子送出、兩個鉀離子帶入。

當刺激讓膜電位上升，一旦越過約 −55 mV 的閾值，電壓門控鈉通道會在極短時間內全部打開，形成「全有或全無」的動作電位。

把閾值想成推倒骨牌的最小力氣：不夠就什麼都不會發生，夠了就一路倒到底。

2.2　突觸傳遞

訊號抵達軸突末梢後，鈣離子經電壓門控鈣通道流入，促使突觸小泡與細胞膜融合並釋放神經傳導物質。

階段主要離子膜電位
靜止鉀離子外流為主−70 mV
去極化鈉離子大量內流+30 mV
再極化鉀離子外流回到 −70 mV

2.3　離子通道

鈉通道打開約 1 毫秒後，失活閘門關上，鈉離子停止內流；鉀通道較慢打開，帶動再極化。這段「不反應期」確保訊號只往前、不往回傳。
