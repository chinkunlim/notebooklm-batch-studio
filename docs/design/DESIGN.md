## 各版本關鍵代碼與特性說明

### Version 3: 奢華黑膠唱機核心 (Turntable Engine)
- **非均向性反射**：`conic-gradient(from 0deg, #111412 0deg, #323b34 45deg, ...)` 呈現十字高光流轉。
- **唱臂物理可供性**：播放狀態 `turntableTonearm` 旋轉 24° 落針至音軌；暫停時平滑回彈 -6° 歸位。
- **270° 環形進度弧線**：SVG 圓弧配合 `stroke-dashoffset` 與發光刻度微珠（Luminous Bead），鐘錶空間感知。

### Version 4: 9 大產出物全景平鋪矩陣 (9-Tool Overview Grid)
- **免反覆切換**：原本需在「脈絡輸入」「結構提煉」「主動提取」三個分頁來回點擊，改為 3x3 響應式卡片矩陣平鋪，點選任何工具立即在下方展開舞台。
- **自選呈現架構**：可在自訂頁面自由切換為「全景九宮格」「垂直工具羅盤」「常用釘選列」「認知三階梯」。
- **全設備 RWD 根治**：樣式同時綁定 `@media (max-width: 680px), [data-device="iphone"]`，無論在桌面上點選 iPhone (416) 模擬器或真機訪問，皆自動切換為垂直單欄重排與元件縮放。

## 設計理念與需求總表（Version 5 依據）

> 由 Claude Code 於 2026-11-02 從本專案所有對話紀錄（`.agents/conversations/`，含 Antigravity 與 Claude 的問答回覆）整理。之後任何介面修改都要先對照這張表；**只能增加使用者可搭配的選項，不能刪除既有模式。**

### 產品與架構
- 之後會發展成個人的 e-learning 平台，要能持續加功能；**影片**目前沒有，但版面與命名都要先預留。
- 遞進式旅程：總覽 → 課程 → 研讀工作室 → 弱點複習 → 批次排程，越往內越專注。
- 單頁多視圖、不重新整理；語音在不同頁面之間持續播放（底部常駐迷你播放器）。
- 點標題回首頁；頁首的狀態與按鈕分開。
- 9 項 Gemini Notebook 產出物（語音摘要、影片摘要、報告、測驗、資料表、資訊圖表、學習卡、心智圖、簡報）都要能處理，用詞與 Gemini Notebook Studio 對齊。
- 網頁可看回課件（PDF / PPTX）並直接標出重點；開啟時可自動進入專注模式。

### 學生與使用者
- 「美好的心情，才會想要去使用」：溫暖、友善、不像嚴肅教科書，也不機械化。
- 載入動畫要吸引學生，但不干擾。
- 使用者自主：不同人需求不同，全部做成選項讓使用者自己搭配（使用者原話：「都要」「全部」「都給我選」「都要給我自行搭配」）。
- 配色是固定幾組給人挑（不是每個人都對顏色敏感），每組都有日光與暗夜。
- 學習掌控感：自己決定今天讀多少；首頁有「放鬆漫遊 / 衝刺」兩種節奏。
- 對話框要能用底部按鈕、✖、點外面關閉；選資料夾用點的，不輸入路徑。
- 批次：可勾選產出物、「每份 PDF / 全部整合 / 兩者」、測驗兩種版本、報告互動與靜態版；可暫停、繼續，看得到上傳在內的詳細進度，額度用完自動續跑。
- Markdown 要正確顯示；**任何地方都不要出現橫向捲軸。**

### 教育與心理學
- 視覺分級：70–80% 靜態穩定的基底，20–30% 動態只用來引導視線、標記當下焦點，步驟結束就停。
- 認知負荷：移除裝飾性動態、過多框線與層層卡片；用心智圖、資訊圖表促進理解。
- 格式塔：接近、相似、連續（章節路線）、封閉（柔和底色而非粗框）。
- 雙重編碼與記憶鷹架：空間隱喻、視覺錨點、**語意化色彩**（每種產出物固定一個色相）、密集段落後留白。
- 一個畫面不超過 3 個視覺焦點；不用製造焦慮的倒數或警示。
- 情感化設計（本能、行為、反思）、自我決定論（自主、勝任）、Fogg 觸發點（聽完語音立刻提示做 5 題測驗）。
- 已實作、要在畫面上呈現：Leitner 1/3/7/14/30 天、遺忘曲線、提取練習、目標梯度、漸進揭露、學習循環。
- 三種風格「認知心流 / 編輯典藏 / 實戰刻意練習」都要能切換。

### 視覺
- 喜歡的參考：Brainie、Studdy、Orely、圖 4 課程影片版面；subframe e-learning 範例 1、4、9、19、21、22、24；黑膠唱機、環形進度播放器、聲波可視化。
- 配色：圖 1、圖 4 最接近，久看不累；預設為圖 4 暖紙底（#f4eee6）、白色卡片、Brainie 森林綠。
- 典雅、高級、不干擾、能專注；柔和但不死氣沉沉。
- 動畫緩慢柔和；選取時用「滑動」的膠囊指示器。
- 要嘛純圖示、要嘛純文字，不混用；不用 emoji；圖示用 CSS 從圖示庫引入，不自己畫。
- 每個元素都要有用途；不用中文首字放大。
- 只有首頁用三欄，其餘左右兩欄。
- 黑膠：保留 v4 那版，盤面不寫字，唱臂落針，標題切換要有播放器的感覺，下方控制同步；可切換弦波、環形頻譜、矩陣聲譜，三種切換方式（點唱盤翻轉、分段按鈕、地平線疊加）都要。

### 使用者指出的細節問題（不能再犯）
- padding / margin 不一致、最上排左右距離不同、中間幾行突然靠左；card / div 切太細。
- 不該換行的地方換行；按鈕不必滿版；1.25x 按鈕奇怪且無法切換；圓圈內數字擁擠；播放圖示變形。
- 切換 iPhone / iPad 時不會重新排列與縮放（見 ISSUE-026）。
- （2026-11-02 第二輪）認知三階的間距鬆散 → 改成三個並排的柔和群組，由左到右呈現「輸入 → 結構 → 提取」。
- 倍速不要獨立在播放器外 → 放進播放控制列，顯示目前倍速（如 1×），點擊才跳出選單。
- 簡報等產出物不要另外「開啟」 → 一律直接嵌入顯示（簡報翻頁、資訊圖表依裝置切換、報告全文、心智圖、資料表、測驗、學習卡）。
- 批次排程的設定變少了 → 依 `GenerationOptions` 補回每項產出物的生成參數、課程語言、章節範圍、考試日期、模擬考題數、額外指示與 Prompt 編輯；左右兩欄不必平分，設定欄寬、進度欄窄。
- 研讀工作室左右不等長、浪費空間，且三塊的用意不清 → 提供兩種版面讓使用者選：「主舞台」（左看講義或任一產出物，右邊固定播放器與重點）與「雙欄」（左講義，右播放器與產出物，右欄自己捲動）。
- （第三輪）首頁在 iPad 寬度下「掌握程度」橫跨全寬、「本週節奏」獨佔一列，看起來很空 → 掌握程度變寬時改左右排列；本週節奏併入「今日策略」。
- 播放器已經獨立顯示，產出物裡就不再重複放「語音摘要」。
- 常用釘選要真的能用 → 每張卡片右上角有圖釘可增減，未釘選的列在下方，選擇會記住。
- 研讀版面再加第三種「上下」：播放器在上（寬螢幕時段落列在右側），講義與產出物在下，都用全寬。
- 額外指示不會取代原本的 Prompt，而是加在最後；課程與單項的指示都會套用（`effective_options`、`apply_job_settings`）。只有「檢視 / 編輯 Prompt」會改寫整份 Prompt。介面上要寫清楚。
- （第四輪）播放器上方的視覺切換列拿掉，點唱盤就能切換；唱盤中央不放綠色弦波線條。
- 學習產出物可以拖曳排序（鍵盤 Alt + 方向鍵），全景矩陣、垂直羅盤、常用釘選、認知三階都跟著同一個順序；預設順序要記住、可還原。
- 日光 / 暗夜 / 自動（跟系統）三選一，預設「自動」。
- 配色可新增、刪除自訂配色（背景、主色、強調色，暗夜版自動產生），原本五組保留。
- 有左右欄的地方（研讀工作室主舞台與雙欄、批次排程）可以拖曳調整欄寬、按兩下還原，右欄可以收合；收合播放器時改顯示迷你播放器。
- **目前的設計就是預設值**；使用者的每項調整都要記住，並且在「設計與自訂」可以一鍵全部恢復預設（自訂配色保留）。
- （第五輪）左右欄要有最小寬度（主欄 420px、右欄 320px），太窄時改成單欄；收合按鈕平常不顯示（滑過分隔線才出現），收合後改成右側的浮動圓形按鈕（研讀頁用唱片圖示）。
- 研讀頁的區塊（講義與學習產出物、語音摘要、本講重點、講義）可以拖曳上方把手換位置或換欄，每種版面各自記住。
- 不可以出現內層捲軸（不要寫死高度）；右欄只在放得下時才固定。
- 底部迷你播放器取消：只有播放中、而且完整播放器不在畫面上時，左側 Dock 才出現唱片圖示，點開是小卡片（標題、進度、暫停、回到研讀）。
- 所有唱片圖示都用同一個設計（與大唱盤同比例），不再用扁平的四色塊。
- 使用方法、專注模式、設計與自訂移到 Dock 下方，與四個頁面圖示分開；選取框改成與頁面同色、往右接進內容區的分頁形狀（凹角弧線）。
- 課程設定是每門課各自保存（後端 `/api/courses/{code}/options`），畫面上要寫明目前是哪一門課。
- （第六、七輪）所有左右兩欄（研讀工作室、課程目錄、弱點複習、今日學習卡、批次排程）都能拖曳調整寬度；收合有動畫（欄寬收到 0、內容淡出），收合後改用右下角的浮動按鈕展開（滑過顯示文字）。
- 側欄選取：收合時是較大的圓圈往右推、嵌在側欄邊緣平滑的圓弧凹口裡（一整條曲線，不能有尖角）；展開側欄時是延伸到內容區的色帶加上前端的圓圈，與參考圖一致。展開 / 收合時圖示與圓圈大小不變，凹口隨側欄寬度連續變形。
- 「玻璃質感」可在設計與自訂開啟（預設關閉）：卡片半透明、背景柔和光暈。
- （第八輪）講義內容不設閱讀寬度上限，跟著欄位寬度走（收合右欄後就是全寬）。
- 收合後的浮動按鈕：固定大小的圓形按鈕（展開側欄圖示），文字只寫「展開」並以提示框顯示，不改變按鈕大小（避免滑過時跳動）；可以拖曳，放開後會滑到最近的角落（預設右下角，距邊緣 24px、不蓋到側欄），角落會記住。
- （第九輪：套用前優化）換頁用 View Transitions 交叉淡化（側欄保持即時動畫，播放中的唱片在頁面間連續轉場）；首頁數字由 0 計數；測驗答對放大加勾號、答錯輕晃後標出正解；學習卡評分後滑出、下一張浮上；學習循環打勾描線，三步完成時溫和提示；排序與區塊移動用 FLIP 平滑滑動；首次載入顯示骨架畫面（微光只跑幾次就停）。
- 效能：播放器迴圈只在播放時執行；玻璃質感在捲動時暫時取消模糊；不再使用 `transition: all`。
- 無障礙：分段切換是 radiogroup、可用方向鍵；播放器快捷鍵（空白鍵播放/暫停、← → 15 秒、`,` `.` 倍速）；區塊可用 Alt + 方向鍵移動；狀態變化會讀給螢幕閱讀器；所有配色的提示字對比提高到 4.5:1 以上；系統要求高對比時加深邊框。
- 觸控：長按卡片拖曳排序、按住把手拖曳區塊；觸控裝置上圖釘、收合鈕、把手常駐顯示。
- （第十輪）弦波、環形、聲譜改成和黑膠同材質：同一顆深色光澤圓盤、同一條環形進度弧線，線條清晰（依螢幕密度繪製），暫停時靜止。小唱片（首頁、側欄、播放小卡）跟著目前選的視覺顯示。從側欄唱片按「回到研讀」（或播放中切到研讀工作室）時，唱片會從側欄飛出、放大，落回播放器原本的位置。
- （第十一輪）側欄唱片點開是完整的迷你播放器：目前視覺的唱片、播放狀態、標題與課程、可拖曳 / 點擊的進度條（鍵盤 ← → 15 秒）、時間、倒退 15 秒 / 上一段 / 播放暫停 / 下一段 / 快轉 15 秒、倍速、回到研讀。唱片飛行改成每次隨機的曲線路徑（貝茲曲線、旋轉、升起的陰影、放大略超過再落定），而且雙向：回到研讀時從側欄飛進播放器；播放中離開研讀工作室時，從播放器飛回側欄。
