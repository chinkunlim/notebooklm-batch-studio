# ISSUE-032：頁面中間切換分頁時動畫卡頓、側欄跳動

- **狀態**：🟢 已根治 (Resolved)
- **發現日期**：2026-11-02
- **Agent**：`claude-code`
- **任務**：`TASK-011`

## 1. 現象

捲到頁面中間再切換分頁，畫面卡一下、側欄跳動、底部短暫出現空隙；相鄰分頁切換又快得不自然。

- **錯誤訊息**：沒有錯誤訊息（畫面問題）
- **重現步驟**：在研讀總覽捲到中間 → 點側欄切換到弱點複習；或在相鄰兩個分頁間來回切換
- **影響範圍**：所有頁面切換

## 2. 根本原因

換頁用瀏覽器的 View Transitions：側欄被另外截圖，新頁面沿用舊的捲動位置，比較短的頁面讓捲動被夾回，兩張截圖對不上；選取圈用很強的 ease-out，短距離顯得急促。

## 3. 修正或規避方式

改成腳本控制：舊頁淡出、看不到時回到頂端、新頁浮上；側欄不動；選取圈用柔和的進出曲線，時間依距離加長；scrollbar-gutter: stable 避免左右位移。（相關程式碼註解加 `Refs: ISSUE-032`）

## 4. 防回歸

切換時每一幀記錄側欄位置與高度必須不變（Playwright / 瀏覽器實測）；不要對固定側欄使用 view-transition-name。
