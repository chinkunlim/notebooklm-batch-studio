# ISSUE-018：學習專區的測驗分頁打不開測驗 1/2/3

- **狀態**：🟢 已根治 (Resolved)
- **發現日期**：2026-11-01
- **Agent**：`claude-code`
- **任務**：`TASK-009`

## 1. 現象

「學生研讀專區」的互動測驗只有「研究所深入版」「概念刷題版」兩顆按鈕，預設組合產生的測驗 1/2/3 與全課程模擬考都無法作答；預設開啟的進階版沒有生成時，整個分頁是空的。

- **錯誤訊息**：「尚未生成此章節測驗」
- **重現步驟**：用預設組合跑完一門課，進學習專區 → 互動測驗
- **影響範圍**：`entrypoints/static/index.html` `loadQuizForChapter`

## 2. 根本原因

測驗分頁的按鈕是早期寫死的兩種進階測驗；後來預設改用測驗 1/2/3，但分頁沒有跟著改，也沒有考慮重新生成後的新版本（v2 檔名）。

## 3. 修正或規避方式

依目前範圍列出已完成的測驗（各講：測驗 1/2/3、學術精研、概念刷題；全課程：模擬考與兩種進階考），預設開第一個；每種都開最新版本（依檔名前綴 `quiz_1_v2` 等）。

人工驗證（瀏覽器）：見 TASK-009 交接紀錄。
