# ISSUE-022：交卷後測驗被重置並跳回第 1 講

- **狀態**：🟢 已根治 (Resolved)
- **發現日期**：2026-11-01
- **Agent**：`claude-code`
- **任務**：`TASK-009`

## 1. 現象

在學習專區交卷後，只有一個彈出視窗顯示分數；關掉後測驗被重新載入、看不到哪題錯；若在第 3 講作答，畫面還會跳回第 1 講。

- **錯誤訊息**：無
- **重現步驟**：學習專區選第 3 講 → 互動測驗 → 交卷
- **影響範圍**：`entrypoints/static/index.html` `submitQuizAttempt`、`loadStudyCourseData`

## 2. 根本原因

交卷後呼叫 `loadStudyCourseData(code)` 更新統計，但這個函式每次都會選回第一講並重新渲染目前分頁，等於整份測驗被重新載入。

## 3. 修正或規避方式

`loadStudyCourseData(code, keepView)`：交卷後只更新統計與側欄，不換講次也不重繪分頁。
交卷結果改在頁面上顯示：分數卡、每題對錯標記與解析、「只重做錯題」、「為什麼？」（請 NotebookLM 依講義解釋）、全課程模擬考的各章答對率。

## 4. 防回歸

瀏覽器驗證（隔離測試資料）：第 2 講交卷後仍停在第 2 講、結果卡與 30 題對錯標記正確、只重做錯題 26/26。
