# ISSUE-021：測驗正確答案大多是 A

- **狀態**：🟢 已根治 (Resolved)
- **發現日期**：2026-11-01
- **Agent**：`claude-code`
- **任務**：`TASK-009`

## 1. 現象

整門課 590 題中 422 題（72%）的正確答案在 A，7 份測驗 30 題全部是 A；全部選 A 就能拿到 70%。

- **錯誤訊息**：無
- **重現步驟**：學習專區做任一測驗、全部選 A
- **影響範圍**：`services/converters/quiz_converter.py`

## 2. 根本原因

NotebookLM 產生的選項傾向把正確答案放第一個，程式照原順序保存。

## 3. 修正或規避方式

解析時用題幹的雜湊值當種子，把選項打亂成固定順序（同一題每次順序相同），再重算正確答案位置；
選項含「以上皆是／A 與 B」等指涉其他選項的文字時保留原順序。對同一門課重算後分布為 A 150、B 155、C 142、D 143。

## 4. 防回歸

`tests/test_guides_and_reports.py`：`ChoiceShuffleTest`。
