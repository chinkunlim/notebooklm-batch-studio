# ISSUE-033：啟動時舊的瀏覽器快取可能蓋掉記在本機的偏好

- **狀態**：🟢 已根治 (Resolved)
- **發現日期**：2026-11-02
- **Agent**：`claude-code`
- **任務**：`TASK-011`

## 1. 現象

偏好改存在本機資料庫後，啟動時套用快取會觸發儲存（配色、釘選、頭像），可能在伺服器資料回來前把舊值送出去。上線前測試發現。

- **錯誤訊息**：沒有錯誤訊息（資料可能被舊值覆寫）
- **重現步驟**：在 A 瀏覽器改配色 → 在 B 瀏覽器（有舊快取）重新整理 → 舊的配色可能被送回伺服器
- **影響範圍**：設計與自訂的所有偏好（配色、釘選、頭像等）

## 2. 根本原因

套用偏好的函式（renderPalettes、renderPins、applyAvatar）本身會呼叫 save()，而 save() 會排程送到伺服器；首次套用用的是瀏覽器快取。

## 3. 修正或規避方式

save() 在伺服器偏好讀回之前與套用偏好期間都不送出（prefsReady / prefMute）；第一次伺服器沒有資料時才上傳瀏覽器原有設定。（相關程式碼註解加 `Refs: ISSUE-033`）

## 4. 防回歸

清空快取後重新整理，確認伺服器上的值不變（tests/test_preferences.py 覆蓋 API；瀏覽器實測覆蓋前端）。
