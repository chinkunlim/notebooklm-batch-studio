## 4. 測試步驟

### A1 學習網頁 B 版（整本書）

1. 使用者同意後，確認課程是暫停狀態，在課程「變更產出模式…」勾選「整本書學習網頁」（`course_learning_site`），確認只排入 1 件工作（實際入口在執行前由 Agent 再確認一次）。
2. 暫時「開始」課程，等佇列領取工作後立刻「暫停」（暫停的課程佇列不會領取，見 SPEC-021 驗收紀錄）。
3. 約 15–20 分鐘後：`03 Notes/NotebookLM/` 出現 `course_learning_site.html`；Studio 名稱改為「Whole-Book Learning Site」加前綴的形式（Gemini 會存成檔名，ISSUE-071）。
4. 通過：在研讀工作室開啟網頁、主控台無錯誤、作答後重新開啟進度保留；TASK-040 結案。

### A2 整本課本切割

1. 把有書籤的整本 PDF 放在該課 `01 Materials/` 最上層（檔名不限）。
2. 打開網頁「批次排程」頁，60 秒內最上方出現「偵測到課本：…（N 章，M 章已存在）」卡片。
3. 按「預覽並切割」，確認：輸出資料夾是原本的課本資料夾、已有章節顯示「已存在」、新章節顯示「建立」；沒問題再按確認。
4. 卡片沒出現時改用「進階工具 → 課本切割…」；顯示「找不到章節書籤」表示 PDF 沒有書籤，無法切割。
5. 通過：講次只多出新章節、既有講次與來源不變、佇列沒有新工作（新章節要等該課下一次跑工作時才上傳，不產生產出）。預期數字：心理學研究法 17 章（現有 6 章），生涯諮商與實務 18 章（現有 10 章）。

### A3 Gemini 額度到點續跑

1. 下次筆記排程遇到 Gemini 額度上限時，「筆記生成 → 筆記排程」卡片顯示「預計 HH:MM 繼續」，該章狀態 `quota_wait`。
2. 到了該時間後 5 分鐘內，該章自動從未完成的模組繼續，最後縫合成整章。
3. 通過：截圖兩個時間點的卡片，`DATA_DIR/logs/` 有續跑紀錄。

### A4 完成通知

1. 下次某門課所有產出跑完時，macOS 右上角跳出「課程 … 全部產出完成（N 項）」。
2. 沒跳出時，檢查「系統設定 → 通知」是否允許終端機／App 的通知，並把 `DATA_DIR/logs/` 中 `course complete` 相關的 log 貼給 Agent。

### A6 真 Chrome 登入與文獻下載（SPEC-022）

1. 網頁「設計與自訂 → 登入狀態」，Gemini Notebook 那一列按「登入」→ 跳出 Chrome（新的、乾淨的視窗）→ 在裡面登入 Google → 自動關閉，網頁顯示「已登入 Gemini Notebook」，狀態「就緒」。
2. 若 Google 仍顯示「這個瀏覽器可能不安全」，截圖給 Agent（記入 ISSUE）。
3. 文獻頁對之前會一直循環的網站（如 worktribe）的文獻按「下載」，遇到 Cloudflare 勾選一次。通過：PDF 下載成功；不通過：記錄網站名稱與畫面。
