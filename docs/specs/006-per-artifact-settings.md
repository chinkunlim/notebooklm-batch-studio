# SPEC-006：每一項產出各自的生成設定

- **狀態**：Implemented <!-- Draft | Approved | Implemented | Deprecated -->
- **日期**：2026-11-01
- **相關任務 / ADR**：TASK-009 / ADR-005

## 1. 目標

使用者在網頁上一次設定好，系統就自動在 Gemini Notebook 產生所有內容，不必到 Gemini Notebook 一項一項手動操作。
除了「整門課共用」的產出設定（SPEC-005），還要能針對**某一種產出**、甚至**某一講的某一份產出**單獨設定，
例如：第 3 講的測驗 2 改成簡答題、題數較少；整門課的資訊圖表改成橫式。

## 2. 使用情境

- 測驗 1 用選擇題，測驗 3 想混入簡答題。
- 某一講內容特別多，語音想選「長」，其他講維持「標準」。
- 全課程模擬考想多一點題目、難度偏難。

## 3. 設計：三層設定，越具體越優先

| 層級 | 存在哪裡 | 例子 |
|---|---|---|
| 1. 專案預設 | 程式內 `GenerationOptions` 預設值 | 資訊圖表直式、測驗題量「較多」 |
| 2. 課程設定 | `courses.generation_options`（已完成，SPEC-005） | 這門課的語音都用「簡短摘要」 |
| 3. 單項設定 | `artifact_jobs.style_options`（欄位已存在、目前未使用） | 第 3 講測驗 2：簡答題、題量較少 |

生成時依序合併：專案預設 → 課程設定 → 該工作的單項設定，只覆蓋有填的欄位。
「重新生成」時預設沿用上一版的單項設定，也可以在重新生成前修改。

### 每種產出可以單獨設定的欄位

| 產出 | 可設定 | 來源 |
|---|---|---|
| 測驗（各講、全課程） | 題量（較少／標準／較多）、難度（簡單／中等／困難）、**題型（選擇題／簡答題）**、是否包含圖片、額外指示 | 題型、圖片、語言：notebooklm-py **下一版**才有（目前未發布） |
| 閃卡 | 數量、難度、額外指示 | 0.8.6 已支援 |
| 語音 | 形式、長度、額外指示 | 已支援 |
| 資訊圖表 | 方向、詳細程度、風格、是否輸出裝置版本 | 已支援 |
| 投影片 | 形式、長度、下載格式（PDF／PPTX） | 已支援 |
| 影片 | 形式、風格 | 已支援（保留，預設不勾） |
| 報告 | 額外指示 | 已支援 |

## 4. 介面

- **課程頁「⚙️ 產出設定」**：設定這門課所有同類產出（加入課程後調整；加入視窗本身不另設 ⚙️，避免畫面過於複雜）。
- **課程頁任務表**：每一列加「⚙️ 設定」，只改這一份（存到該工作的 `style_options`）；尚未開始的工作直接套用，已完成的提示「按重新生成才會套用」。
- 課程設定另外可改：產出語言、全課程模擬考題數（10–100）、整門課的補充指示、測驗難度（依測驗而定／全部簡單／中等／困難）、影片自訂風格描述。
- 表單只顯示該產出可用的欄位；notebooklm-py 尚未支援的欄位（題型）顯示為灰色並註明「等待函式庫支援」。
- HTTP：`GET/PUT /api/jobs/{id}/options`；MCP：`get_job_options`、`set_job_options(confirm)`。

## 5. 驗收標準

- [x] 單項設定覆蓋課程設定，課程設定覆蓋預設值（單元測試）
- [x] 尚未開始的工作改設定後，生成時帶入新參數
- [x] 重新生成沿用上一版單項設定
- [x] 不支援的欄位不會送給 Gemini Notebook

## 6. 未決問題

- 題型（選擇／簡答）要等 notebooklm-py 下一版發布；發布後升級並開放此欄位。
- 簡答題的本機格式：目前題目卷／答案卷與互動測驗只支援選擇題，簡答題需要新的版面與作答方式（學習專區改為「自己作答後看參考答案」）。

## 7. 實作摘要

- `domain/models.py`：`GenerationOptions` 新增 `quiz_difficulty`、`extra_instructions`、`video_style_prompt`；`effective_options()` 合併課程與單項設定（補充指示兩層都保留）。
- `services/course_settings.py`：`apply_job_settings()` 在執行時把補充指示接到 prompt 後面、帶入合併後的設定；`get_job_options` / `set_job_options`；重新生成沿用上一版的單項設定。
- 測試：`tests/test_job_settings.py`。

## 8. 第二批（課程管理）

- **加入時設定**：加入課程視窗有「⚙️ 進階產出設定」，只送出和預設值不同的項目；設定在任何工作開始前寫入。
- **課程暫停**：取消「加入後立即開始」＝以暫停狀態加入；課程頁可「▶️ 開始生成／⏸ 暫停這門課」。HTTP `POST /api/courses/{code}/pause|start`、MCP `set_course_paused(confirm)`。
- **章節範圍**：整門課產出可設 `chapter_range`（例如 `1-3`），只用那些講次的來源，標題前綴與 prompt 都跟著範圍。
- **刪除課程**：`DELETE /api/courses/{code}`、MCP `delete_course(confirm)`；刪本機紀錄，產出移到 `DATA_DIR/deleted/`，講義 PDF 與 Gemini Notebook 不動。
- **沿用筆記本**：重新加入時，Gemini Notebook 上已有同名筆記本就沿用，已上傳的 PDF（依檔名）不重傳；可在加入視窗取消。
- 測試：`tests/test_course_admin.py`。
