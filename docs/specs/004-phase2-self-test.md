## 1. 目標

NotebookLM 上做 quiz 不會記錄成績。第二階段在本機網頁做題，記錄分數與錯題，找出弱點並針對弱點複習。
本文件只定範圍，細節在第一階段完成後補齊。

## 2. 使用情境

- 在本機網頁選一門課、一講、一份 quiz 作答，交卷後看分數與解析。
- 考前打開「錯題本」，只重做答錯過的題目。
- 依考試日期，網頁告訴使用者「今天該複習哪幾講」。

## 3. 需求

### 必須 (Must)
- 讀取 SPEC-002 的統一 quiz 格式作答；記錄每次作答（題目、選擇、對錯、時間）。
- 成績：每講、每份 quiz、每門課的正確率與趨勢。
- 錯題本：答錯的題目自動收集；答對 2 次後移出。
- 弱點：正確率最低的講次與主題排行。
- 透過 MCP / OpenAPI 查詢成績與錯題（例如「我 BIO101 哪一講最弱？」）。

### 可選 (Nice to have)
- 依弱點請 NotebookLM 針對該講再出一份 quiz（走 SPEC-001 的佇列）。
- 依考試日期排間隔複習計畫。
- 多課程儀表板。
- Flashcards 在網頁上翻卡複習並記錄熟練度。

### 不做 (Out of scope)
- 多人排行榜、分享成績。
