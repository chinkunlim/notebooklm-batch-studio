# SPEC-028：study/ 新資料夾自動判斷學期、列出科目並補齊 01–05

- **狀態**：Implemented（使用者 2026-11-26）<!-- Draft | Approved | Implemented | Deprecated -->
- **日期**：2026-11-26
- **相關任務 / ADR**：SPEC-027（新課程資料夾卡片）、SPEC-014、SPEC-016

## 1. 目標

使用者原話：「study/ 內會開新的文件夾的話，就要自動抓到是什麼學年-學期，然後也要抓取該學年-學期內的文件夾的科目，同時補齊所有文件夾。」

2026-11-26 使用者建立 `study/115-2/專題製作/`（空的、沒有課號），網頁沒有任何提示，因為 SPEC-027 只認學校格式（`CP__31000-課名`）且要等「加入課程」才補建 01–05。

成功的樣子：在 `study/` 建立 `115-2/` 與其中的科目資料夾後，不用按任何按鈕，最多 60 秒內每個科目資料夾都有 `01 Materials`～`05 Assignments`；「批次排程」頁列出 115-2 的每個科目（包含沒有課號的「專題製作」），加入時再填課號。

## 2. 使用情境

- 新學期：使用者在 Finder 建立 `study/115-2/`，再建立 `CP__40000-新課/`、`專題製作/` → 網頁開著或 `watch` 在跑 → 兩個資料夾自動多出 01–05 → 批次排程卡片列出兩科，「專題製作」標示「需要課號」→ 按「加入課程…」在精靈填課號後加入。

## 3. 需求

- **必須 (Must)**：
  1. **學期判斷**：`study/` 底下名稱符合學期格式（例如 `115-2`，`TERM_PATTERN`）的資料夾是學期；其他名稱忽略。
  2. **科目判斷**：學期資料夾裡每個未登錄、非隱藏的子資料夾都是科目；學校格式（`課號代碼__數字-課名`）帶出課號與課名，其他名稱（如「專題製作」）課名＝資料夾名、課號留空並標示 `needs_course_no`。只處理目前學期以後（SPEC-027 規則）。
  3. **自動補齊**：對上述每個科目資料夾補建缺少的 01–05（`StudyLayout.ensure_tree`；已有別名不重建）；不搬動、不改名、不刪除任何檔案；不處理舊學期未登錄資料夾與學期資料夾以外的位置。**2026-11-26 使用者追加**：已登錄、未封存的課程（資料夾在 `study/<學期>/<課程>/`）也一起補齊；已封存的課程不動。
  4. **何時執行**：網頁伺服器啟動時跑一次、之後每 60 秒一次（背景執行緒，不論佇列是否啟動）；`watch` 執行時也每 60 秒一次。不呼叫 Gemini Notebook、不登錄、不排程。
  5. **加入沒有課號的科目**：精靈填的課號用於 `study/<學期>/` 內非學校格式的資料夾，課程代碼為 `<學期>_<課號>`，資料夾名稱不變；課名欄位有填就用。這類資料夾沒填課號時拒絕加入並說明。
  6. 三入口：`GET /api/study/new-course-folders` 與 MCP `list_new_course_folders` 回傳 `needs_course_no`、`created`；網頁卡片顯示「需要課號」並在精靈預填學期與課名。
- **不做 (Out of scope)**：自動登錄、自動排程；改名資料夾；學期名稱以外格式（例如「115學年第2學期」）。
