# ADR-008：研讀工作室 v05 外殼：側欄導覽、設計與自訂移到側欄底部、靜態檔依職責拆分

- **狀態**：Accepted <!-- Proposed | Accepted | Superseded by ADR-NNN -->
- **日期**：2026-11-02
- **Agent**：`claude-code`
- **任務**：`TASK-011`

## 1. 背景與問題

使用者確認 docs/design/version_05_claude_template.html（v05）並要求套用到專案。v05 與 ADR-007 有三處不同：頂部分頁改成左側圖示側欄（研讀總覽、研讀工作室、弱點複習、批次排程）；「設計與自訂」不再是第 4 個主分頁，而是側欄底部工具（與使用方法、專注模式、展開側欄並列）；播放器四種視覺（黑膠、弦波、環形、聲譜）共用同一套繪圖，迷你播放器與飛行唱片取代唱臂之外的單一形態。舊介面是 2,239 行的 index.html（含 1,600 行內嵌腳本）加上四個 JS 檔，功能都已接上真實 API。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| A. 分階段移植（先外殼，再逐頁搬功能） | 每一步都能用、各自 commit | 中途新舊介面並存，較慢 |
| B. 一次全部移植，保留所有功能函式與 API 呼叫，只換外殼與標記（採用） | 一次到位、不會有新舊混搭的畫面；功能邏輯不重寫，風險集中在畫面 | 改動量大，需要完整瀏覽器驗證 |
| C. 依 v05 重寫全部功能 | 程式最整齊 | 容易漏掉舊版的小功能（信心評分、混合複習、番茄鐘、重點畫線等），風險最高 |

## 3. 決策與理由

採用 v05 外殼，一次全部移植（使用者選擇 all at once）。1) 保留所有既有功能函式與 API 呼叫，只換外殼與畫面標記：內嵌腳本搬到 studio-app.js（研讀功能）、studio-batch.js（批次排程）、studio-settings.js（設定表單與對話框）；v05 外殼拆成 studio-shell.js、studio-player.js、studio-bench.js、studio-start.js，每檔 ≤ 800 行並有完整 JSDoc。2) 工作台每個項目對應一個常駐的功能面板（講義閱讀器、測驗、學習卡、報告檢視器、AI 家教），點選時把面板移進舞台，不重建、不遺失作答狀態；同一講只載入一次。3) 播放器直接播放該講的 audio 產出（<audio>），黑膠與其他視覺跟著真實播放狀態；上一段 / 下一段改成上一講 / 下一講（後端沒有段落時間點）。4) 「設計與自訂」偏好存在瀏覽器 localStorage（v05.*），學習紀錄仍在後端。5) 課程設定加入考試日期欄位（API 早已支援，舊介面沒有欄位）。ADR-007 的視覺分級、九宮格免分頁、雙軌 RWD、原型獨立歸檔仍然有效；只有「設計與自訂為頂部第 4 主分頁」與「唱臂為唯一播放形態」由本 ADR 取代。

## 4. 影響與代價

正面：所有頁面一致的 v05 設計，五組配色、日光 / 暗夜 / 自動、三種研讀版面、四種產出物排列、可調欄寬與收合、迷你播放器；功能與舊版相同、API 不變、173 個測試通過。代價：圖示字型（lucide-static）與 Noto 字型從 CDN 載入，離線時圖示會缺；偏好設定換瀏覽器會消失（移植待辦：/api/preferences + MCP 工具）。之後新增功能面板要同時加進 TOOLS / PANEL_FOR（studio-shell.js）與 index.html 的 panelHome。
