# ADR-007：研讀工作室認知視覺分級、奢華留聲形態與自主掌控架構

- **狀態**：Accepted
- **日期**：2026-11-02
- **Agent**：`antigravity`

## 1. 背景與問題

在學生研讀工作台的開發過程中，面臨三大設計心理學與互動架構挑戰：
1. **認知負荷與視線疲倦（Cognitive Load & Distraction）**：傳統播放介面常堆砌隨意亂動的波形或平淡文字，造成視覺喧鬧，分散對核心講義的專注力；或過度簡化導致畫面呆滯死氣沉沉。
2. **階層切換疲勞（Tab Fatigue）**：先前產出物工作台強制使用「脈絡輸入」「結構提煉」「主動提取」三階分頁，使用者必須頻繁點擊頁籤才能找到對應檔案。
3. **設備模擬器與響應式 RWD 破版**：在桌面瀏覽器點擊切換手機模式時，因視窗本體未變而未觸發 CSS Media Query，造成橫向溢出。

## 2. 評估過的方案

| 方案 | 優點 | 缺點 |
|---|---|---|
| A. 單純扁平現代風格（Flat Design） | 開發最快、元件簡單 | 缺乏本能層美感與微儀式感，使用者反饋「死氣沉沉、不倫不類」 |
| B. 強制階層鷹架（Strict Triad Disclosure） | 具備強大教育學分類邏輯 | 降低自主掌控感，反覆點擊分頁造成切換疲勞 |
| C. 認知與視覺雙軌架構（Dual-Process Tiering & Agency） | 兼顧美學儀式感、免切換九宮格矩陣、全設備雙軌 RWD，並提供極致自主搭配 | 需精細調整非均向性反射、物理唱臂旋轉動態與畫布渲染效能 |

## 3. 決策與理由

選擇 **方案 C**，落實為系統架構核心：

1. **視覺分級機制 (Visual Tiering)**：
   - 70-80% 靜態基底（柔和卡片容器、8pt 網格、低彩度配色），建立心理安全感。
   - 20-30% 動態焦點引導（非均向性光澤黑膠盤面、唱臂下旋落針物理反饋、270° 環形進度弧線軌道）。
2. **解除強制分層，預設全景九宮格矩陣 (9-Tool Overview Grid)**：
   - 9 大產出物一次整齊平鋪，點選任一項目即時展開，徹底消滅頁籤切換疲勞；並於自訂分頁保留 4 種呈現架構切換。
3. **頂部獨立主分頁「設計與自訂」**：
   - 與進度看板、研讀工作室、批次排程並列同級，集中管理外觀、頭像、架構與聲學風格。
4. **雙軌響應式選擇器 (Dual-Target RWD)**：
   - 樣式同時綁定 `@media (max-width: 680px), [data-device="iphone"]`，根治模擬器容器與真實手機之自適應重排與縮放。
5. **獨立原型歸檔機制 (Versioned Prototyping)**：
   - 所有探索版本（Version 1 ~ 4）獨立歸檔至 `designs_archive/`，嚴禁在原型確認前污染生產程式碼庫 (`src/`)。

## 4. 後果

- 產出 `docs/specs/009-study-studio-ui-redesign.md` 作為正式移植依據。
- 建立 `.agents/skills/design-psychology-master/` 審查工具，確保 8pt 網格、視覺分級與色彩對比度 100% 達標。
- 透過 `mockups_gallery.html` 提供高保真互動展示，零污染保留原始 `src/` 程式碼。
